# 빚오프 기능 안내

빚오프는 개인회생 상담부터 서류 준비, 사건 분석, 신청 문서 작성과 최종 검토까지 이어 주는 업무 도구입니다. 고객이 낸 자료를 담당자가 여러 화면에 다시 옮겨 적는 일을 줄이고, 어떤 자료를 근거로 문서가 작성됐는지 함께 확인할 수 있도록 구성했습니다.

고객은 자신의 진행 상황과 준비할 자료를 확인합니다. 직원은 상담을 정리하고 자료의 부족한 부분을 보완합니다. 변호사는 정리된 사실과 계산, 검토가 필요한 쟁점을 보고 최종 문서를 확인합니다. 세 역할이 보는 화면은 다르지만 같은 사건의 자료와 이력을 공유합니다.

## 상담 내용이 문서가 되는 과정

**상담 신청 → 세부 상담 → 필요한 서류 안내 → 제출·보완 → 내용 추출 → 계산·쟁점 검토 → 1차 문서 작성 → AI 검토·담당자 보완 → 변호사 최종 승인** 순서로 진행합니다.

상담 신청만으로 서류를 일괄 요청하지 않습니다. 담당자가 세부 상담을 마친 뒤 소득 형태, 채무, 재산, 거주 형태, 가족 상황과 관할 법원을 바탕으로 필요한 자료를 정합니다. 예를 들어 급여소득만 있는 고객에게는 급여와 재직을 확인하는 자료를 안내하고, 사업 관련 자료는 사업 사실이 있는 경우에 연결합니다.

받은 서류에서 원문과 추출값을 함께 보고, 틀린 값만 고친 뒤 서류별로 검토 완료를 한 번 저장합니다. 필요한 자료의 페이지·항목 추출과 전체 원문 대조가 끝나야 계산과 1차 문서 작성으로 이어집니다. 시간초과나 읽지 못한 부분이 있으면 그 단계에서 기다리며 이전 자료와 작성본은 보존합니다. 소득·재산 등 확인된 값은 문서에 담고, 아직 판단할 수 없는 내용은 보완 목록으로 남깁니다. 직원과 변호사는 매 단계의 원문, 처리 결과, 수정 이력을 열어볼 수 있습니다.

## 어떤 정보가 어디에 쓰이나요?

| 확인하는 정보 | 주로 살펴보는 자료 | 이 정보가 하는 일 |
| --- | --- | --- |
| 직업과 소득 | 상담 기록, 급여명세서, 재직증명, 소득 증빙 | 필요한 소득 서류를 정하고 월수입과 소득의 지속성을 검토합니다. |
| 채무와 차입 경위 | 부채증명, 거래내역, 고객 진술 | 채권자별 금액을 정리하고 채무가 늘어난 사정을 설명합니다. |
| 재산과 거주 상황 | 계좌 잔액, 재산 조회, 보험, 임대차·거주 자료 | 재산목록과 주거비 검토에 연결합니다. |
| 가족과 생활비 | 가족관계, 가구 정보, 지출 증빙 | 실제 생활 상황을 설명하고 부양·생계비 판단에 필요한 내용을 모읍니다. |
| 관할과 적용 기준 | 법원별 안내, 관련 법령, 실무준칙 | 서류의 종류·기간·발급 조건과 계산·작성 기준을 확인합니다. |
| 작성·검토 결과 | 작성 문서, 보완 이력, 확인된 법원 결과 | 오류를 고치고 다음 사건에서 참고할 수 있는 자료를 쌓습니다. |

같은 숫자라도 의미를 구분합니다. 연봉을 월급으로 사용하거나, 예금 잔액을 생활비로 설명하지 않도록 원문과 함께 확인합니다. 같은 계좌가 여러 서류에 나와도 재산을 중복 합산하지 않습니다.

## 현재 확인된 범위

2026년 10월 4일 기준으로 공식 서식의 기재 항목에 맞춰 박지우 가상사례의 연습자료 29종·53쪽을 준비했습니다. 급여·계좌·채무·주거·보험·퇴직금 자료의 금액과 기간을 서로 대조하고, 추출한 내용이 작성 문서로 이어지는지 확인했습니다. 자료에서 읽을 수 있는 내용과 담당자의 법률 판단·서명이 필요한 칸은 구분합니다. 검사 결과와 새 사건의 시작 상태는 [변경사항과 확인 범위](implementation-status.md), [테스트 안내](testing.md)에 있습니다.

AI의 문장 검토에서 금액의 의미가 맞지 않는 경우에는 검토용 사실 요약을 남깁니다. 가상자료에 없는 주민등록번호·연락처·서명이나 미확정 법률 판단은 임의로 채우지 않습니다. 작성과 검토 기능이 동작한다는 점과 실제 사건의 인가 여부는 구분해서 봐야 합니다. 개별 사건의 인가 확률을 확정적으로 예측하거나 법원에 자동 접수하는 기능은 제공하지 않습니다.
