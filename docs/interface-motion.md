# 화면에서 느껴지는 진행과 변화

고객 화면과 직원·변호사 화면은 같은 흐름으로 움직입니다. 처음 접속하면 브랜드 표시와 차분한 배경빛, 화면이 준비되고 있다는 안내가 나타납니다. 실제 내용을 기다리는 동안에는 카드 형태의 자리 표시자가 보여, 빈 화면만 보고 기다리지 않도록 했습니다.

페이지를 이동하면 제목과 주요 카드가 짧은 간격을 두고 자연스럽게 들어옵니다. 아래쪽 내용은 스크롤로 해당 영역에 도착했을 때 한 번 나타납니다. 문서를 검증하는 동안 진행 수치가 갱신되거나 같은 자료를 다시 불러오는 경우에는 이미 본 카드가 다시 등장하지 않습니다. 숫자와 상태만 바뀌므로 진행 상황을 차분하게 따라갈 수 있습니다.

누를 수 있는 버튼과 대시보드 카드는 마우스를 올렸을 때 약간의 움직임과 그림자로 반응합니다. 단순히 정보를 보여주는 카드에는 같은 효과를 강제로 넣지 않았습니다. 선택한 메뉴와 탭, 키보드로 이동한 입력칸도 현재 위치를 알 수 있도록 표시합니다.

화면 위의 짧은 이동 표시와 로딩 자리 표시자는 내용을 준비하고 있음을 알려주는 장식입니다. 실제 사건 진행률은 기존 단계 안내와 검증 건수로 보여 줍니다. 새로운 디자인이 완료되지 않은 분석을 완료처럼 표시하거나 가상의 진행률을 만들지는 않습니다.

입력 중인 글, 선택한 서류, 뒤로 가기 이력과 스크롤 위치는 기존 기능이 계속 관리합니다. 움직임을 추가하는 기능은 이 내용을 수정하지 않습니다. 원문 PDF와 문서 검토 창도 등장 효과의 대상에서 제외해 읽기와 확인을 방해하지 않도록 했습니다.

기기 설정에서 ‘동작 줄이기’를 선택하면 등장 효과와 반복 움직임을 끕니다. 효과가 실행되지 않거나 브라우저에서 지원하지 않아도 내용은 항상 표시됩니다.

화면 표현은 공통 모듈 `apps/shared/motion.js`와 `apps/shared/motion.css`에서 관리하며, 두 화면의 시작 페이지에서 함께 불러옵니다. 기능별 화면 구조나 사건 처리 순서를 바꾸지 않고 같은 표현을 적용할 수 있습니다.
