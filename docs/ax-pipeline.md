# 상담 내용이 업무로 연결되는 방식

상담에는 금액뿐 아니라 그 금액이 생긴 사정이 들어 있습니다. “월급을 받는다”, “가족이 대신 갚았다”, “최근 차를 팔았다”는 말은 각각 확인할 자료와 문서에 설명할 내용이 다릅니다. 빚오프는 이런 정보를 먼저 정리해 서류 요청과 이후 분석에 연결합니다.

## 첫 신청과 세부 상담을 나눕니다

고객은 신청 화면에서 자신의 상황을 남깁니다. 담당자는 신청 내용을 읽고 세부 상담을 요청한 뒤 소득, 채무, 주거와 가족 상황을 더 구체적으로 확인합니다. 담당자가 상담 완료를 기록하면 정리된 상담 내용에서 필요한 정보를 찾기 시작합니다.

상담에 나온 정보는 우선 고객의 진술로 보관합니다. 서류로 확인한 사실과 구분해야, 나중에 금액이나 시점이 달라졌을 때 어느 내용을 다시 확인할지 알 수 있습니다.

## 상담에서 확인하는 주요 요소

| 상담에서 드러나는 상황 | 더 확인하는 내용 | 연결하는 자료와 업무 |
| --- | --- | --- |
| 회사에서 급여를 받음 | 근무처, 재직 기간, 월급과 공제액 | 급여·재직·입금 자료를 요청하고 소득을 정리합니다. |
| 사업이나 프리랜서 수입이 있음 | 수입 기간, 필요경비, 실제 남는 금액 | 사업·소득·경비 자료를 요청합니다. |
| 월세·전세로 거주함 | 보증금, 월세, 실제 부담자 | 계약·납부 자료를 재산과 지출 검토에 연결합니다. |
| 가족이 채무를 대신 갚음 | 지급자, 지급일, 자금 출처, 다시 갚아야 하는지 | 송금·채무 확인·약정 자료를 모아 남은 채무를 검토합니다. |
| 최근 돈을 빌리거나 재산을 처분함 | 금액, 시기, 사용처, 현재 남은 돈 | 거래내역과 사용처 자료를 진술서와 재산 검토에 연결합니다. |
| 가족을 부양하거나 특별한 지출이 있음 | 실제 부양 관계, 의료·양육 등 비용 | 가족관계와 지출 증빙으로 생활 상황을 설명합니다. |
| 보험·차량·부동산을 보유함 | 소유 관계, 평가 기준, 담보, 환급액 | 재산 관련 자료를 요청하고 가치 검토에 연결합니다. |
| 세금 체납이나 과거 절차가 있음 | 세목·금액, 과거 사건과 종결 시점 | 채권자목록과 신청 내용에서 확인할 항목을 만듭니다. |
| 소득이 끊겼거나 연금을 받음 | 현재 근로 상태, 수급 여부와 기간 | 자격·소득·연금 자료를 확인합니다. |
| 법원의 보완 요구가 도착함 | 요구 내용, 필요한 자료, 실제 송달일 | 요구별 보완 항목과 확인할 기한을 정리합니다. |

이 요소들은 필요한 준비를 찾기 위한 기준입니다. 가족 수만으로 부양을 인정하거나, 소득이 있다는 이유만으로 인가 가능성을 확정하지는 않습니다.

## 상담과 서류가 다른 경우

예를 들어 상담에는 월수입 355만원이라고 적혀 있고, 급여명세서에는 총급여 355만원·공제 35만원·실수령 320만원이 적혀 있을 수 있습니다. 이때 세 금액의 뜻을 구분해 보관하고, 소득 검토에서는 어떤 기준의 금액을 쓰는지 확인합니다.

“가족이 카드대금을 갚아줬다”는 진술도 마찬가지입니다. 금융회사에 대한 채무는 줄었어도 가족에게 다시 갚아야 할 돈이 있을 수 있습니다. 완납 사실, 송금 내용과 가족 간 약정을 연결하고, 최종 법률관계는 검토 항목으로 남깁니다.

자료에 값이 없으면 ‘미확인’, 서로 다른 값이 있으면 ‘내용 확인 필요’로 남깁니다. 뒤 단계에서는 그 차이를 숨기지 않고 보완 질문과 작성 문서의 검토 목록에 전달합니다.

## 법률 자료는 언제 쓰나요?

관할 법원과 사건의 특징에 맞는 법령·법원 안내를 찾아 서류 선정, 쟁점 검토, 문서 작성에 참고합니다. 공식 자료는 출처와 본문을 함께 보관하므로 직원은 적용 근거를 열어볼 수 있습니다.

사건에서 확인한 사실과 공개 법률 자료는 용도가 다릅니다. 다른 사건의 판결이나 좋은 작성 사례가 있어도 그 사건의 사정을 현재 고객의 사실처럼 가져오지 않습니다. 현재 사건에 해당하는 논점과 설명 순서를 참고합니다.

## 다른 상담 도구와 연결하려면

현재는 고객 신청과 사무소 상담 화면에서 시작할 수 있습니다. 별도로 상담 기록을 받아 사건 처리에 연결하는 접수 기능과 외부 업무 도구용 예제도 준비돼 있습니다.

외부 도구가 맡는 일은 상담 기록 전달과 진행 상황 확인입니다. 자료 보관, 접근 권한, 계산, 문서 검토와 승인 이력은 빚오프에서 관리합니다. 같은 상담을 반복 전송하면 사건이 중복 생성될 수 있으므로 신규 접수는 무조건 재시도하지 않고 먼저 기존 작업을 확인해야 합니다.

연결을 준비하는 담당자는 아래 자료를 참고할 수 있습니다.

- 요청 항목과 경로: 실행 중인 [API 안내](http://localhost:8000/docs)
- 외부 업무 도구 예제: [n8n 연결 파일](n8n-local-workflow.json)
- 현재 상담 준비 규칙: [상담 규칙 코드](../apps/api/rulebook.py)

n8n 파일은 아직 실제 n8n 환경에서 실행 검증한 연결이 아닙니다. 같은 PC의 로컬 API를 대상으로 비활성 상태로 제공하며, 사용할 때는 접수 인증과 직원 로그인 정보를 별도로 등록해야 합니다. 기존 작업은 예제의 `existing_run_id`로 다시 조회할 수 있습니다. 작업 조회는 일정 시간 후 종료되지만 사건 처리 자체를 취소하지는 않습니다. 이 예제에 초안 자동 승인이나 외부 발송은 포함하지 않았습니다.
