# 고객 포털 이용 안내

고객 포털은 상담 신청부터 서류 제출, 보완 요청, 담당자와의 대화까지 한곳에서 확인하는 화면입니다. 고객이 보낸 신청과 자료는 담당 직원·변호사의 같은 사건에 연결됩니다. 고객은 본인 사건만 볼 수 있으며, 사무소의 내부 판단이나 다른 고객의 자료는 공개되지 않습니다.

접속 주소는 **http://localhost:5173**입니다. 처음 연습하는 경우에는 [테스트 안내](testing.md)의 계정과 가상자료를 사용하세요.

## 로그인 전에 볼 수 있는 내용

| 메뉴 | 제공하는 내용 |
| --- | --- |
| 메인 | 서비스 소개와 상담 신청으로 가는 입구 |
| 개인회생이란 | 절차, 준비할 자료, 개시·인가·면책의 차이에 대한 기본 안내 |
| Q&A | 자주 묻는 질문 검색, 분야별 안내, 연결된 공식 출처 |
| 고객 후기 | 고객이 공개에 동의한 실제 이용 후기 |
| 내 사건 | 로그인 후 상담 신청 또는 본인 사건 확인 |

상단 메뉴로 이동할 수 있으며, `?page=guide`, `?page=faq`, `?page=reviews`, `?page=case` 주소로 해당 화면을 바로 열 수도 있습니다. 공개 안내에는 검토 시점과 출처를 함께 표시합니다. 개별 사건에 적용할 내용은 담당자가 자료와 관할을 확인합니다.

## 상담을 신청하고 담당자 안내 받기

로그인 후 사건이 없으면 **내 사건 → 상담·신청 시작**이 나타납니다. 이름, 관할 법원, 현재 상황을 적고 자료 활용에 동의한 뒤 신청합니다. 관할을 모르면 상담 중 확인하도록 선택할 수 있습니다.

신청하면 수임번호가 부여되고 담당 직원·변호사에게 전달됩니다. 이때는 **상담 신청 접수** 단계입니다. 신청 본문만으로 분석하거나 서류를 요청하지 않습니다.

담당자가 **세부 상담 요청**을 보내면 고객에게 알림이 도착합니다. 고객은 **담당자 문의**에서 안내를 읽고 답변할 수 있습니다. 전화나 대면으로 상담한 경우에는 담당자가 확인한 내용을 기록합니다. 담당자가 상담 기록을 완료하면 그 내용을 기준으로 필요한 서류 선정과 이후 자동 처리가 시작됩니다. 최초 신청, 추가 답변, 정리된 상담 기록은 구별하여 보관합니다.

## 내 사건에서 하는 일

| 화면 | 고객이 확인하거나 할 수 있는 일 |
| --- | --- |
| 진행 상황 | 현재 단계, 지금 준비할 일, 담당자 안내 확인 |
| 제출 서류 | 요청별 기관·계좌·기간·발급 안내 확인, 파일 제출, 이전 제출 자료 확인 |
| 담당자 문의 | 세부상담 답변, 궁금한 점 전달, 담당자 메시지 확인 |

같은 종류의 서류라도 은행·계좌·대상 기간이 다르면 요청을 나눠 보여줍니다. 제출한 파일은 명의와 종류, 기간, 필요한 범위 등을 확인합니다. 부족하거나 잘못된 자료가 있으면 사유와 함께 다시 요청하며, 기존 제출·확인 이력은 남깁니다. 상담 내용이 바뀌어 불필요해진 요청은 철회하고 현재 준비할 목록에서 제외합니다.

필요한 자료가 모이고 검토가 끝나면 서류의 글자와 항목을 읽고, 계산과 쟁점 검토를 거쳐 1차 문서를 작성합니다. 고객은 진행 상황에서 다음 단계를 확인할 수 있습니다. 작성이 끝나도 담당자의 보완과 변호사의 최종 검토가 남아 있으며, 법원의 인가를 뜻하지는 않습니다.

고객 화면에는 수임번호와 진행 단계를 표시합니다. 시스템 내부 사건 번호는 표시하지 않습니다.

## 알림과 상담 도우미

우상단 알림 버튼에 미확인 개수가 표시됩니다. 상담 안내, 서류 요청·보완, 메시지 등 알림의 종류와 내용을 목록에서 확인하고 해당 사건 화면으로 이동할 수 있습니다. 읽음 상태는 계정별로 관리합니다.

오른쪽 상담 도우미는 모든 페이지에서 열 수 있습니다. 로그인 전에는 공개된 Q&A에서 관련 안내를 찾습니다. 로그인 후에는 본인 사건의 요청 항목과 등록된 안내를 바탕으로 답합니다. 확인할 근거가 부족하거나 답변 처리가 어려우면 그 상태를 알리고 기본 안내를 제공합니다.

**직원 연결**을 선택하면 고객이 전달한 내용이 사건 메시지와 담당자 알림으로 남습니다. 담당자의 답변은 **담당자 문의**에서 확인합니다. 실시간 상담원 통화나 문자·이메일 발송 기능은 아닙니다. 상담 도우미의 질문 원문은 외부 추론 서비스로 보내지 않습니다.

## 고객 후기

로그인 고객은 본인에게 연결된 실제 사건의 경험을 작성하고 공개에 동의할 수 있습니다. 실명·연락처 등 개인정보와 인가 보장 표현은 게시할 수 없습니다. 가상 테스트 사건으로는 후기를 작성할 수 없으며, 후기나 성과 수치를 임의로 채워 넣지 않습니다.

작성자는 **내가 작성한 후기 → 공개 동의 철회**에서 후기 내용을 삭제할 수 있습니다. 담당자는 권한이 있는 사건의 문제 후기를 숨길 수 있습니다. 후기는 사건별 경험이며 인가 가능성을 보장하거나 자동으로 인가 통계에 포함되지 않습니다.

## 화면과 모바일 이용

메인과 소개 페이지에는 따뜻한 이미지와 짧은 설명을 배치하고, 메뉴별로 필요한 내용을 찾아볼 수 있게 구성했습니다. 카드가 나타나는 효과와 움직임을 넣되, 기기에서 움직임 줄이기를 선택하면 그 설정을 따릅니다. 소개 페이지의 이미지 카드와 녹색 안내 카드도 높이를 맞춰 정리했습니다.

휴대전화처럼 화면이 좁은 환경에서도 메뉴와 요청 자료를 확인할 수 있습니다. 현재 알림은 웹 화면에서 확인하며, 모바일 앱의 푸시 알림은 아직 연결하지 않았습니다.

서류 작성 이후 담당자가 하는 일은 [문서 검토와 제출 기록](filing-review.md)에 설명되어 있습니다.
