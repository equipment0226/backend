# 고객 포털 이용 안내

고객 포털은 상담 신청부터 서류 제출, 보완 요청, 담당자와의 대화까지 한곳에서 확인하는 화면입니다. 고객이 보낸 신청과 자료는 담당 직원·변호사의 같은 사건에 연결됩니다. 고객은 본인 사건만 볼 수 있으며, 사무소의 내부 판단이나 다른 고객의 자료는 공개되지 않습니다.

서류 발급의 예외 조건은 내부 항목명 없이 **“특별 사정이 있으면 예외 검토”**로 안내합니다. 고객과 사무소의 요청 카드에 같은 문구를 사용합니다.

접속 주소는 **http://localhost:5173**입니다. 처음 연습하는 경우에는 [테스트 안내](testing.md)의 계정과 가상자료를 사용하세요.

2026년 10월 4일 마지막 초기화 상태는 **고객·직원·변호사 계정 3개, 사건 0건**입니다. 고객 계정으로 로그인한 뒤 사용자가 직접 이하늘 가상사례의 상담을 신청하고, 담당자의 세부상담 안내부터 진행합니다. **연습자료 ZIP**은 등록된 사건의 이름에 맞는 제출용 PDF 묶음을 제공합니다. 해당 이름의 연습자료가 없으면 다른 사람의 자료를 대신 제공하지 않고 안내합니다. 법률 판단 예시 JSON과 검산 자료는 제출용 묶음에서 제외합니다.

## 로그인 전에 볼 수 있는 내용

메뉴와 내 사건의 탭은 각각 주소와 방문 이력을 가집니다. 예를 들어 메인에서 안내를 읽고 내 사건의 제출 서류로 이동했다면, 브라우저 뒤로가기로 방금 보던 화면을 차례로 다시 볼 수 있습니다. 앞으로가기도 같은 순서로 동작하며 돌아온 화면의 스크롤 위치를 복원합니다.

상담·신청 시작 화면과 실제 신청서도 나누었습니다. 신청서를 작성하다 안내 화면으로 이동한 뒤 돌아오면 같은 브라우저 탭 안에서 입력하던 내용을 이어갈 수 있습니다. 상담 내용과 문의 초안은 주소나 방문 이력에 넣지 않고 메모리에만 보관하며, 로그아웃하면 지웁니다. 새로고침은 해당 화면을 다시 여는 동작이며 저장하지 않은 초안의 영구 보관을 뜻하지는 않습니다.

| 메뉴 | 제공하는 내용 |
| --- | --- |
| 메인 | 서비스 소개와 상담 신청으로 가는 입구 |
| 개인회생이란 | 절차, 준비할 자료, 개시·인가·면책의 차이에 대한 기본 안내 |
| Q&A | 자주 묻는 질문 검색, 분야별 안내, 연결된 공식 출처 |
| 고객 후기 | 고객이 공개에 동의한 실제 이용 후기 |
| 내 사건 | 로그인 후 상담 신청 또는 본인 사건 확인 |

상단 메뉴로 이동할 수 있으며, `?page=guide`, `?page=faq`, `?page=reviews`, `?page=case` 주소로 해당 화면을 바로 열 수도 있습니다. 공개 안내에는 검토 시점과 출처를 함께 표시합니다. 개별 사건에 적용할 내용은 담당자가 자료와 관할을 확인합니다.

## 상담을 신청하고 담당자 안내 받기

로그인 후 사건이 없으면 **내 사건 → 상담·신청 시작**이 나타납니다. 이름, 관할 법원, 현재 상황을 적고 자료 활용에 동의한 뒤 신청합니다. 관할을 모르면 상담 중 확인하도록 선택할 수 있습니다.

신청하면 수임번호가 부여되고 담당 직원·변호사에게 전달됩니다. 이때는 **상담 신청 접수** 단계입니다. 신청 본문만으로 분석하거나 서류를 요청하지 않습니다.

담당자가 **세부 상담 요청**을 보내면 고객에게 알림이 도착합니다. 고객은 **담당자 문의**에서 안내를 읽고 답변할 수 있습니다. 전화나 대면으로 상담한 경우에는 담당자가 확인한 내용을 기록합니다. 담당자가 상담 기록을 완료하면 그 내용을 기준으로 필요한 서류 선정과 이후 자동 처리가 시작됩니다. 최초 신청, 추가 답변, 정리된 상담 기록은 구별하여 보관합니다.

## 내 사건에서 하는 일

| 화면 | 고객이 확인하거나 할 수 있는 일 |
| --- | --- |
| 진행 상황 | 현재 단계, 지금 준비할 일, 담당자 안내 확인 |
| 제출 서류 | 요청별 기관·계좌·기간·발급 안내 확인, 파일 제출, 이전 제출 자료 확인 |
| 담당자 문의 | 세부상담 답변, 궁금한 점 전달, 담당자 메시지 확인 |

같은 종류의 서류라도 은행·계좌·대상 기간이 다르면 요청을 나눠 보여줍니다. 제출한 파일은 명의와 종류, 기간, 필요한 범위 등을 확인합니다. 부족하거나 잘못된 자료가 있으면 사유와 함께 다시 요청하며, 기존 제출·확인 이력은 남깁니다. 상담 내용이 바뀌어 불필요해진 요청은 철회하고 현재 준비할 목록에서 제외합니다.

요청 카드에서 **여러 파일을 함께 선택해 제출**할 수 있습니다. 예를 들어 월별 급여명세서나 계좌별 거래내역을 선택하면 파일명과 용량을 목록에서 확인하고, 잘못 고른 파일을 빼고 제출할 수 있습니다. 한 번에 최대 20개, 파일마다 10 MB, 전체 50 MB까지 받습니다. 제출 중에는 선택한 파일마다 처리 중 상태를 표시하며, 접수가 끝나면 각 파일의 결과를 보여줍니다. 파일 형식이나 요청 확인에 문제가 있으면 일부만 접수하지 않고 전체를 다시 확인하도록 안내합니다. 통신 문제로 접수 여부가 불명확하면 먼저 사건을 새로고침해 중복 제출을 피하세요.

이미 접수되었거나 확인을 마친 요청에도 **자료 추가 제출**을 할 수 있습니다. 이전 원본은 보존하고 새 파일을 추가하며, 해당 요청은 추가 자료를 포함해 다시 확인합니다. 철회된 요청에는 제출하지 않습니다. 파일 접수는 서류 검토 완료와 다릅니다. 필요한 기관·계좌·기간의 자료와 모든 원본 페이지가 갖추어졌는지까지 확인합니다.

요청별로 나누기 어려우면 제출 서류 화면의 **한 번에 넣기**에서 ZIP을 올릴 수 있습니다. 압축 안의 실제 내용을 읽어 명확히 맞는 요청에 연결하므로 파일명을 일정한 규칙으로 바꿀 필요가 없습니다. 종류·기간·계좌·명의를 확실히 판단하지 못한 자료는 별도 확인 자료로 접수하여 담당자가 살펴봅니다. 진행 화면에는 원문 확인, 분류, 저장 단계와 파일마다 연결된 요청 또는 확인이 필요한 이유를 표시합니다. 창을 닫아도 접수 작업은 계속되며 같은 버튼으로 다시 열어 진행 상황을 확인할 수 있습니다.

ZIP은 압축파일 50 MB, 안의 파일 최대 100개까지 받으며, 개별 파일은 10 MB, 압축을 푼 전체 용량은 100 MB 이하여야 합니다. ALZ·EGG는 알집에서 ZIP으로 다시 압축해 주세요. 지원하지 않는 설정·참고 파일은 제외 내역을 표시합니다. 암호화된 압축파일이나 위험한 압축 구조는 전체를 접수하지 않습니다. 압축파일 기능이 아직 반영되지 않은 서버에서는 ZIP을 풀고 기존 요청 카드의 복수 첨부를 이용하라는 안내를 제공합니다.

전송 중 연결이 끊기면 먼저 기존 접수 기록을 찾아 진행을 이어갑니다. 서버 목록에 작업이 없으면 **같은 파일 다시 접수**로 처음 선택한 ZIP을 재전송할 수 있습니다. 같은 접수번호를 유지하고 파일 내용도 대조하므로, 응답만 늦게 도착한 작업이 있더라도 원본을 중복 저장하지 않습니다. 저장은 완료됐으나 후속 처리를 다시 확인해야 하는 경우에는 완료 결과와 별도 안내를 함께 표시합니다.

제출한 서류는 내용을 읽어 사건에 필요한 항목으로 정리합니다. 담당자는 서류별로 추출이 끝났는지 확인하고, 원문과 추출값을 함께 대조하여 틀린 부분을 고칩니다. 이 과정의 상세 화면과 검토 기록은 직원·변호사 업무공간에서 확인합니다.

모든 필요한 서류의 추출과 검토가 끝나면 계산과 쟁점 검토를 거쳐 1차 문서를 작성합니다. 고객은 진행 상황에서 다음 단계를 확인할 수 있습니다. 작성이 끝나도 담당자의 보완과 변호사의 최종 검토가 남아 있으며, 법원의 인가를 뜻하지는 않습니다.

고객 화면에는 수임번호와 진행 단계를 표시합니다. 시스템 내부 사건 번호는 표시하지 않습니다.

## 알림과 상담 도우미

우상단 알림 버튼에 미확인 개수가 표시됩니다. 상담 안내, 서류 요청·보완, 메시지 등 알림의 종류와 내용을 목록에서 확인하고 해당 사건 화면으로 이동할 수 있습니다. 읽음 상태는 계정별로 관리합니다.

오른쪽 상담 도우미는 모든 페이지에서 열 수 있습니다. 로그인 전에는 공개된 Q&A에서 관련 안내를 찾습니다. 로그인 후에는 본인 사건의 요청 항목과 등록된 안내를 바탕으로 답합니다. 확인할 근거가 부족하거나 답변 처리가 어려우면 그 상태를 알리고 기본 안내를 제공합니다.

**직원 연결**을 선택하면 고객이 전달한 내용이 사건 메시지와 담당자 알림으로 남습니다. 담당자의 답변은 **담당자 문의**에서 확인합니다. 실시간 상담원 통화나 문자·이메일 발송 기능은 아닙니다. 상담 도우미의 질문 원문은 외부 추론 서비스로 보내지 않습니다.

## 고객 후기

로그인 고객은 본인에게 연결된 실제 사건의 경험을 작성하고 공개에 동의할 수 있습니다. 실명·연락처 등 개인정보와 인가 보장 표현은 게시할 수 없습니다. 가상 테스트 사건으로는 후기를 작성할 수 없으며, 후기나 성과 수치를 임의로 채워 넣지 않습니다.

작성자는 **내가 작성한 후기 → 공개 동의 철회**에서 후기 내용을 삭제할 수 있습니다. 담당자는 권한이 있는 사건의 문제 후기를 숨길 수 있습니다. 후기는 사건별 경험이며 인가 가능성을 보장하거나 자동으로 인가 통계에 포함되지 않습니다.

## 화면과 모바일 이용

메인과 소개 페이지에는 따뜻한 이미지와 짧은 설명을 배치하고, 메뉴별로 필요한 내용을 찾아볼 수 있게 구성했습니다. 카드가 나타나는 효과와 움직임을 넣되, 기기에서 움직임 줄이기를 선택하면 그 설정을 따릅니다. 소개 페이지의 이미지 카드와 녹색 안내 카드도 높이를 맞춰 정리했습니다.

휴대전화처럼 화면이 좁은 환경에서도 메뉴와 요청 자료를 확인할 수 있습니다. 현재 알림은 웹 화면에서 확인하며, 모바일 앱의 푸시 알림은 아직 연결하지 않았습니다.

서류 작성 이후 담당자가 하는 일은 [문서 검토와 제출 기록](filing-review.md)에 설명되어 있습니다.
