# 한국 개인회생 계산 엔진

계산은 `apps/api/legal_calculator.py`에서 정수 원/Decimal로 실행하며 LLM을 호출하지 않는다. 같은 사건 입력 버전·계산 입력·정책 버전이면 같은 결과와 해시가 나온다. 이 문서의 구현 범위는 급여소득 개인회생 계산이다. 법원의 인가와 면책 판단은 계산 결과와 별개다.

2026-10-03에 현행 법률 제21490호(2026-10-02 시행) 제579조·제611조·제614조를 원문과 대조했다. 실행 정책은 `data/legal_calculation_rules.json`이며 적용 기간은 2026-10-02~2026-12-31로 제한한다. 미래 연도나 다른 버전의 생계비를 현재 수치로 묵시 적용하지 않는다.

## 계산하는 내용

| 항목 | 구현과 근거 |
|---|---|
| 채무한도 | 담보부 15억원, 그 외 10억원 이하인지 원금과 이자를 합해 비교. 제579조 |
| 소득 | 검토한 월평균 급여소득. 세전은 세금·보험료를 차감하고 세후는 중복 차감 차단. 산정기간과 증빙 필수 |
| 기본생계비 | 서울 2026 중위소득 60%, 원 단위 반올림. 다른 관할은 개별 검토한 인정액을 입력 |
| 부양·추가비용 | 가구원수와 인정 부양인원 구분. 인정 인원·추가 인정액·판단 사유를 입력하고 변호사가 최종 검토 |
| 청산가치 | 자산별 소유지분 평가액에서 근거가 있는 담보·면제·환가비용을 차감. 중복/과다 공제 차단 |
| 현가 | 서울 직무편람의 연 5% 월복리 할인. 인가 전 실제 적립회차에는 할인하지 않음. 회차별 실제 배분액을 할인해 합산 |
| 기간 | 기본 36개월, 청산가치 충족을 위해 필요한 경우 최대 60개월. 개별 법원 결정은 결정 문서와 사유 필수. 서울 원금 전액 변제 단축안도 지원 |
| 우선채권 | 우선채권 원금·이자 전액을 일반 원금/이자보다 먼저 배분. 전액 미변제는 차단 |
| 일반채권 | 우선 원금, 이후 이자. 각 단계에 비례 배분하고 채권 초과 변제 방지 |
| 단수 | 정수 나눗셈 후 소수 잔여가 큰 채권에 1원씩 배정, 동률은 고유 ID 순. 합계는 0원 오차. 법원 공통 단수 규정으로 주장하지 않으며 출력안 검토 대상 |
| 이의 | 이의가 있을 때만 제614조 제2항 최저변제액 적용. 5천만원 미만은 5%, 이상은 3%+100만원, 상한 3천만원. 이의 채권자별 파산 예상배당액도 별도 현가 대조 |

[현행 채무자회생법](https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=290631&efYd=20261002&chrClsCd=010202), [서울회생법원 직무편람](https://slb.scourt.go.kr/rel/information/qna/member_manual.pdf) 인쇄 160~164쪽, [2026 서울 생계비 공지](https://slb.scourt.go.kr/dcboard/new/DcNewsViewAction.work?cbub_code=000221&gubun=41&pageIndex=1&searchWord=&seqnum=19158), [공공기관 LH의 2026 중위소득표](https://apply.lh.or.kr/lhapply/cm/cntnts/cntntsView.do?cntntsId=1201331&mi=1201583)를 정책에 연결했다. 직무편람은 2024년 자료이므로 최신 실무와 개별 결정 적용은 사건 검토에 포함한다. 공지의 HWP 세부 추가생계비 한도를 확보한 것으로 간주하지 않는다.

## 상태와 승인

`calculate_legal(case, payload)`는 `blocked` 또는 `ready_for_review`를 반환한다. 문서가 미검토 상태면 금액 미리보기는 만들지만 확정 가능한 상태로 올리지 않는다. 사건 밖 증빙, 미결 법률 쟁점, 확정 사실과 입력액의 충돌도 차단한다. 금액이 미상인 경우 0원으로 채우지 않는다.

`ready_for_review`도 승인 전 계산이다. API는 별도 변호사 인증으로 계산 입력 해시, 계산 정책 해시, 결과 해시, 사건 입력 버전을 묶어 승인한다. 입력 해시에는 연결한 문서의 원본 해시·검토 상태·본문/페이지 해시도 포함하여 사건 버전 무효화를 우회한 원문 변경도 검출한다. 클라이언트가 payload에 `approval`을 넣어도 계산기의 승인 값은 항상 null이다. 자료·사실·기준이 바뀌면 재계산 후 새 승인을 받는다. 계산 원장과 문서가 같은 스냅샷을 참조해야 한다.

## 로컬 테스트

`examples/legal_inputs.json`은 김가온 합성 사건의 입력이며 실제 사건 사실이 아니다. `evidence_ids`의 fixture ID는 업로드가 반환한 사건 문서 ID로 바꾼다. 자료 대조 전에는 `blocked`가 정상이며, 문서 원문을 검토해 verified로 바꾼 뒤 재계산한다.

합성 급여는 세전 3,100,000원 / 공제 300,000원 / 세후 2,800,000원이다. 1인 기본생계비 1,538,543원, 추가비용·월 위원보수 0원 가정에서 월 변제 여력은 1,261,457원이다. 36개월 채권자 변제총액은 45,412,452원, 적립회차가 0일 때 현가는 42,089,397원(표시상 원 미만 버림)이다. 재산 12,000,000원, 일반채권 원금 75,000,000원·이자 3,000,000원이며 이 안에서는 원금만 일부 변제한다. 임차보증금 공제와 추가주거비 인정 여부는 가상 입력에서 확정하지 않았다.

```powershell
python -m unittest tests.test_legal_calculator -v
```

공식 편람의 현가계수(36회 33.3657012839, 인가 전 3회 적립 시 33.77199540), 법정한도 경계, 이의 유무, 채권자별 청산배당, 세전·세후 동등성, 청산가치 현가 부족, 우선채권 우선배분, 1원 보전, 미검토 증빙, 기간 예외와 변경 해시를 검증한다.

## 자동 확정하지 않는 경우

영업소득·변동소득의 순이익 산정, 별제권 예정부족액과 유보액, 분쟁 채권, 사건별 면제재산 인정, 모든 법원의 최신 세부 생계비표는 현재 범위 밖이다. 해당 유형은 오류/검토 과제로 돌리며 무담보 급여 사례로 바꾸어 계산하지 않는다. 정량 조건 충족만으로 수행가능성·공정성·성실성이나 인가·면책을 단정하지 않는다.
