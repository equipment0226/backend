# 사건 자료를 HTML로 함께 살펴보기

고객 화면과 직원·변호사 화면을 각각 하나의 HTML 파일로 담을 수 있습니다. 서버에 접속하거나 로그인하지 않아도, 자료를 보관한 시점의 화면과 제출서류를 열어볼 수 있습니다. 실제 화면 구성과 권한별 응답을 이용하므로 별도로 만든 화면 예시와는 다릅니다.

현재 자료집은 박지우 가상사건의 1차 작성 이후 담당자 검토 단계를 기준으로 합니다. 사건을 다음 단계로 넘기거나 기존 검토 이력을 고치지 않고, 같은 시점의 자료로 두 파일을 만들었습니다.

## 각 파일에서 볼 수 있는 것

고객용은 사건 진행, 준비할 서류, 제출한 원본, 알림과 상담 메시지를 보여 줍니다. 직원용은 여기에 원문·추출값 대조, 법률쟁점, 계산 이력, 작성 문서, 저장된 법률 근거를 더합니다. 직원과 변호사 화면은 파일 위쪽에서 전환할 수 있습니다. 고객 파일에는 직원 전용 분석과 작성 문서를 넣지 않습니다.

사진·화면 구성·제출 원본·작성 문서가 파일 안에 들어 있습니다. PDF를 미리 보거나 내려받을 수 있고, 메뉴 이동과 뒤로가기, 항목 검색과 상세 열기도 사용할 수 있습니다. 파일 크기가 큰 직원용은 처음 열 때 시간이 조금 걸릴 수 있습니다.

## 수정 체험과 실제 처리를 구분합니다

추출값 수정, 서류 검토, 알림 확인, 메시지 작성은 열린 화면 안에서 체험할 수 있습니다. 위쪽의 **체험 기록**에서 무엇을 바꿨는지 확인하고 목록을 내려받습니다. 새로 열거나 **원래 상태**를 누르면 보관 당시 내용으로 돌아갑니다. 두 파일의 체험 수정은 서로 연동되지 않습니다.

파일과 ZIP을 넣어 보는 기능도 제공합니다. 기존 제출 원본과 내용이 같으면 이름이 달라도 원래 요청에 연결할 수 있습니다. 처음 보는 파일은 분류·추출 대기로 남습니다. HTML 안에서는 새 OCR이나 AI 검토를 실행하지 않습니다.

자료집은 실제 서버에 수정 내용을 보내지 않습니다. 새 분석, 계산 확정, 최종 승인과 법원 제출을 실행하는 버튼은 그 이유를 안내합니다. 고객 상담창도 저장된 사건 정보와 안내문으로 답하며, 새로운 AI 상담이나 직원에게 실제 메시지 전송이 이뤄진 것으로 표시하지 않습니다.

## 추출값과 작성 문서를 나란히 확인합니다

직원 파일의 **추출·서식 대조**를 누르면 서식별 실제 기재값과 공란 사유를 볼 수 있습니다. 서식이나 항목명으로 검색하고, 해당 PDF를 바로 열어 비교할 수 있습니다. 공란은 법률 판단·일정 미확정, 추가 연락·지시 확인, 근거 자료 부족, 접수 후 부여되는 내용, 사용하지 않는 추가 행으로 구분합니다.

원문에는 있는데 본문 칸에 연결되지 않았던 값은 **대조 보완본**에서 확인합니다. 기존 저장 PDF는 그대로 남겨 두고 같은 원문으로 별도 작성한 문서입니다. 보완본이 생겼다고 AI 검토나 최종 승인이 완료된 것은 아닙니다.

**36개월 계산·작성본**에서는 같은 원문으로 산출한 월 변제금과 전체 배분, 사용한 가정을 확인합니다. 계산이 반영된 7종 PDF, 보고서와 편집용 문서, 36회차 배분표를 열거나 내려받을 수 있습니다. 아직 정해지지 않은 실제 납입 시작·종료 날짜는 임의로 채우지 않습니다.

집계는 프로그램에 등록한 서식 칸을 대상으로 합니다. 공식 양식의 모든 선택란·수기 서명·동의까지 작성됐다는 뜻은 아니며 인가 확률로도 사용하지 않습니다.

## 만들고 전달하기

현재 파일은 `reports/park-jiwoo-review/customer-review.html`과 `office-review.html`입니다. Chrome 또는 Edge에서 각 파일을 열면 됩니다. PDF 보기 환경이 지원되지 않으면 내려받아 확인합니다.

화면을 묶는 도구는 `scripts/build_review_html.mjs`입니다. 미리 준비한 권한별 가상사건 자료와 로컬 화면 파일만 읽으며, 환경설정의 비밀키나 로그인 토큰을 가져오지 않습니다. 출력 자료는 공개 코드 저장소에 넣지 않습니다. 직원용에는 원문과 상세 사건자료가 함께 들어 있으므로 파일을 전달할 대상을 구분합니다.
