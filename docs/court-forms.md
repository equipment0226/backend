# 공식 서식 원본과 자동 작성

`apps/api/court_forms.py`는 법원 PDF의 선·표·문구를 유지하고 승인된 사건 값만 정해진 좌표에 배치하는 렌더러다. HTML 문서를 공식 양식처럼 부르는 방식이 아니다. 입력값 출처와 공란·넘침은 뒤에 붙는 대조표에 남는다. 모든 생성물은 `DRAFT`이며 서명, 날인, 정보수신 동의, 기각사유 부존재 진술 체크는 자동 확정하지 않는다.

2026-10-03 대한민국 법원 공개 양식목록에서 실제 다운로드한 파일은 PDF 8개, HWP 9개다. 원본 URL, 목록 URL, SHA-256, 수집일은 `data/court_forms/sources.json`, 원본은 `data/court_forms/originals/`에 있다. 서식의 발행일과 현재 목록에 게시된 날짜를 구별한다. D5100은 파일명에 2021-04-20 시행이 명시된 현 게시본이다. 접수 시점의 변경 공지·안내문 효력까지 자동 확정한 것은 아니다.

|---|---|---|---|
| D5100 | 개인회생절차 개시신청서 | 1–2 | 대법원 공통 |
| D5106 | 개인회생채권자목록 | 1–2 | 대법원 공통, 채권자 첫 4개 표 배치 |
| D5101 | 재산목록 | 1 | 대법원 공통 |
| D5103 | 수입 및 지출에 관한 목록 | 1–2 | 대법원 공통 |
| D5105 | 진술서 | 1–3 | 대법원 공통 |
| D5110 | 가용소득만으로 변제하는 변제계획안 | 1–7 | 대법원 공통 |
| D5115 | 급여소득자 소득증명서 | 1 | 대법원 공통, 사용자 확인 필요 |
| BUSAN-ATTACHMENTS | 부산회생법원 자료제출목록 | 1–4 | 부산 전용, 2026-07-01 시행 |

대법원 공통 7종을 등록된 15개 법원에 연결한다. 각 법원에 서로 다른 7종을 수집했다는 뜻이 아니다. 서울·수원·부산 실무준칙 출처도 법원 프로필에 연결되며, 부산은 실제 별도 제출목록 원본을 포함한다. 서울 제증명신청서 HWP는 원본 보관만 지원한다. HWP 자동 수정이나 다른 법원의 별도 서식까지 완성했다고 표시하지 않는다.

PDF 원본에 들어 있는 작성례의 이름·금액을 실제 사건에 복사하지 않는다. 예를 들어 D5106의 8쪽 작성례와 부속서류 작성례는 생성물에서 제외한다. 담보부 채권, 다툼 있는 채권, 전부명령 등의 별도 부속표는 원본을 참고하여 추가 검토해야 한다. 채권자 5명 이상 또는 빈칸 넘침 값은 별지에 모두 보존하며 배치 검토가 남아 있음을 표시한다.

D5106과 D5110의 별지에는 승인 계산의 **전체 채권자 목록과 입력 상세**를 행 수 제한 없이 포함한다. D5110에는 채권자별 총 변제원금·이자·잔액과 **모든 회차의 모든 채권자 배분액**도 포함한다. 원 단위 배분 때문에 월별 금액이 달라지는 경우 본표의 ‘회차별 별지’가 실제 배분 내역을 가리킨다. 회차별 입금액·회생위원 보수·채권자 변제액과 총합을 대조할 수 있으며 계산·입력·정책 해시를 남긴다. 직원이 시작일을 입력했을 때만 계획 날짜를 표시하고 이를 법원의 확정 납입일로 표현하지 않는다.

## 입력과 검토 경계

우선순위는 현재 사건의 승인 계산 → 확인된 팩터 → 직원 입력 → 추출 후보다. 격리된 사람의 문서나 거절된 후보를 자동 채택하지 않는다. `fields` JSON은 확인된 팩터나 승인 계산을 덮어쓸 수 없다. 계산칸에는 `status=approved`, `approval` 존재, 같은 `input_revision`, `stale=false`인 계산만 연결한다. API는 계산 입력·정책·출력 해시를 다시 대조한다. 승인 계산이 없으면 월변제액·청산가치·현가·법원 인정생계비 칸은 공란이다.

`catalog()`의 `fields`는 `key, label, page, rect, required, font_size, source_kind, read_only`를 제공한다. `rect`는 원본 PDF 좌상단 기준 포인트다. `preview()`는 각 값·출처, 필수 공란, 원본 칸 넘침, 미매핑 값, 원본 해시를 반환한다. 필수 공란이나 넘침이 있으면 `ready_for_review=false`다. `submission_ready`는 언제나 false다. 법원의 인가 또는 전자접수 완료를 뜻하는 플래그를 만들지 않는다.

`render_pdf(template_id, case, fields=None, calculation=None)`는 PDF bytes를 반환한다. 검증되지 않은 계산·다른 관할 전용 서식·개인회생 외 절차·변경된 원본 해시는 거절한다. 자동 경로는 현재 입력 리비전에 묶인 `auto_preparation.passed` 계산도 허용하며 수동 승인 이력과 구분한다.

## 글꼴과 배치

공통 원본에 포함된 한글 서체는 주로 휴먼명조 부분집합이며 일부 문자는 Type3다. 설치된 완전한 동일 폰트가 없어 현재 작성값은 함초롬바탕(`HANBatang.ttf`)을 사용한다. `HMFMOLD.TTF`는 휴먼옛체이므로 휴먼명조로 오인해 사용하지 않는다. 설정한 명조체 또는 바탕체를 선택하며 사용한 실제 폰트·해시를 미리보기와 렌더링 버전에 기록한다.

작성값은 원본 행의 기준선에 맞춰 검정색으로 배치하고 숫자는 우측 정렬한다. 칸 크기에 따라 글자 크기를 조정하며 최소 크기로도 들어가지 않으면 잘라내지 않고 넘침으로 표시한다. 원본 글자와의 충돌 및 미리보기·실제 배치의 일치를 검사한다. 계좌의 은행 접미사, 연도/사건번호, 날짜·변제액 칸을 별도로 배치한다. D5105의 `tenant_name`은 원본의 임차인 성명이며 임대인 이름으로 채우지 않는다.

`reports/court-form-typography.json`과 `.work/court_typography/`에 실제 원본·작성본 비교와 검사 결과를 보존한다. 렌더러가 바뀌어도 기존 PDF를 수정하지 않는다. 새 버전 작성 시 변경된 배치·폰트 서명으로 다시 검토한다.

`.work/court_typography/D5105-grounded-v3.pdf`는 실제 로컬 작성 및 독립 원문 검증을 통과한 합성 사례의 세 문단을 배치한 진술서 비교본이다. 연결된 실행 증적은 `reports/statement-authoring-live.json`이며 법원 제출·인가된 문서로 취급하지 않는다.

## 진술과 원본 조항

D5105의 진술은 상담 메모를 직접 복사하지 않는다. 기본 작성은 근거별 세 문단의 로컬 작성과 독립 원문·금액 검증을 거치며 실패하면 PDF 없이 보류 사유를 기록한다. 직원이 명시적으로 직접 입력한 진술은 검토 필요 상태로 구분한다. 진술 검증 통과를 PDF 전체 검증으로 복사하지 않는다.

D5110 원본의 재산 처분 관련 ‘해당 사항 없음’ 선택 문구는 소유 재산 자체가 없다는 뜻이 아니다. 자동 검증은 원본 선택 조항의 적용 범위와 계산을 별도로 대조하며 재산 매각 변제·지원하지 않는 소득 유형은 이 소득 전용 서식으로 자동 통과시키지 않는다. 서명·동의 및 미매핑된 조항은 검증 범위 밖임을 남긴다.

## 가상 자료

`python scripts/generate_synthetic_case.py`로 `examples/synthetic_case/`와 `examples/synthetic_case_bundle.zip`을 다시 만든다. 자료 전체가 **가상자료·효력없음** 표시를 포함한다. 실제 주민번호·계좌·인감·기관 직인은 없다. 정부 증명서 사칭본이 아닌 테스트 필드와 증빙 레이아웃이다.

김가온 사례의 세후 월급 280만원, 3개월 은행 입출금, 금융기관 채무 7800만원, 자산 1200만원이 서로 대조된다. 가족 차용금 200만원이 최초 합계에 누락된 분기점도 넣었다. `expected.json`은 정답 대조용이며 증빙으로 투입하지 않는다. `legal_inputs_bank_only.json`과 `legal_inputs_family_included.json`으로 7800만원/8000만원 두 안을 비교할 수 있다. 예제의 `fixture-*` 증빙 ID는 업로드 후 실제 문서 ID로 바꿔야 한다.

급여 PDF는 3쪽 모두 텍스트층이 없는 실제 이미지형 PDF다. OCR 테스트는 이를 사용한다. 다른 사람 급여와 1개월 급여는 `edge_cases/`에 따로 있다. `court_previews/`는 공식 양식 위에 가상 값을 배치한 7종의 미승인 미리보기다. 계산칸을 공란으로 남겨 직원이 숫자를 넣어 변호사 계산 승인을 우회하는 데 쓰이지 않는다.

## 검증

`python -m unittest tests.test_court_forms -v`는 실제 원본 해시·PDF 형식, 15개 공통 연결/부산 제한, 원본 페이지 크기와 문자 보존, 작성례 배제, 미승인 계산 차단, 승인값 덮어쓰기 차단, 인적 불일치 자료 배제, 넘침 보존, 가상 금액 대조, 이미지 전용 스캔을 검증한다. 공식 제출용 완성도는 별도로 담당 변호사가 빈칸·서명·특수 채권·법원 추가 요구를 검토해야 한다.
